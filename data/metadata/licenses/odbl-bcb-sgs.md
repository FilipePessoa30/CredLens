# ODbL — applies to: bcb-sgs-20570, bcb-sgs-21112

Both Banco Central do Brasil SGS series in this registry are published
under the **Open Data Commons Open Database License (ODbL) v1.0**, per
the license badge and text on their respective `dadosabertos.bcb.gov.br`
dataset pages, confirmed on 2026-07-23.

Full legal text: <https://opendatacommons.org/licenses/odbl/1-0/>

## What ODbL requires (summary, not a substitute for the full text)

- **Attribute** — credit the source (Banco Central do Brasil) when using
  the data or a derivative of it.
- **Share-Alike** — if you publicly use a substantially modified version
  of the database, it must also be offered under ODbL.
- **Keep open** — technical measures that restrict access to the data (or
  a derivative) in ways ODbL doesn't allow are not permitted.

## Scope note

These are aggregate, national-level macroeconomic indicators, not
individual-level records. There is no personal or bank-secrecy sensitivity
in this data - it is Brazil's own official open-data publication - but it
must still be attributed correctly and never presented as if it described
individual loans (see `docs/sensitive_attributes.md` and
`docs/data_sources.md`).
