# Modeling Output (Phase 8)

Generated by `credlens model ...` - never hand-edited. Everything here
describes a model trained on the real, public **UCI Default of Credit
Card Clients** benchmark (Taiwan, 2005) - not the synthetic CredLens
portfolio, never mixed with it. See `model_card.md` for the mandatory
"Not suitable for real lending decisions" disclosure.

## Contents

- `model_card.md` / `model_card.pt-BR.md` - name/version, intended use, prohibited uses, dataset/target/split, features, metrics, calibration, limitations, risks, governance (EN/PT-BR).
- `technical_report.md` / `technical_report.pt-BR.md` - full methodology: leakage controls, baselines, tuning, calibration, evaluation, operating points, uncertainty, interpretability, subgroup diagnostics, robustness, negative controls, registration gates (EN/PT-BR).
- `manifest.json` - which reports were written, the package version, and a `content_fingerprint` that deliberately excludes the generation timestamp (proven identical across two runs of the same experiment).
- `experiments/<experiment_id>.json` - the compact experiment record (dataset/split hashes, hyperparameters, full metrics, calibration/threshold/subgroup/robustness summaries, dependency versions, status).
- `experiments/<experiment_id>/split_assignment.csv` - the ID-keyed train/validation/test assignment table that locks the split (not a re-derivable-only seed).
- `experiments/<experiment_id>/models/*.joblib` - one fitted pipeline per model kind (Dummy, simple rule, logistic regression, HistGradientBoosting) - **git-ignored**, fully reproducible via `credlens model train --experiment-id <ID> --seed <N>`.
- `tables/<experiment_id>__*.csv` - predictions, thresholds, coefficients, permutation importance, partial dependence, subgroup audit, robustness, split stability, negative controls, champion/challenger comparison - **git-ignored** (regenerable), except where explicitly noted.
- `figures/<experiment_id>__*.png` - the 16 required figures (prevalence, ROC, PR, calibration, lift, cumulative gains, event rate by decile, confusion matrix, champion/challenger, coefficients, permutation importance, partial dependence, a local explanation, subgroup performance, stress test, seed stability).
- `models/<model_id>.joblib` + `<model_id>.manifest.json` - the registered `candidate` model (never `production`, never auto-promoted to `champion`) - the only modeling binary artifact that IS versioned, since it is small and deliberate.

## Regenerating this directory

```bash
uv sync --extra analysis --extra modeling
uv run credlens model data-audit
uv run credlens model validate-features
uv run credlens model create-split --experiment-id EXP_demo --seed 42
uv run credlens model train --experiment-id EXP_demo --seed 42
uv run credlens model evaluate --experiment-id EXP_demo
uv run credlens model compare --experiment-id EXP_demo
uv run credlens model explain --experiment-id EXP_demo
uv run credlens model audit-groups --experiment-id EXP_demo
uv run credlens model stress-test --experiment-id EXP_demo
uv run credlens model register --experiment-id EXP_demo --model-id MODEL_demo
uv run credlens model validate --model-id MODEL_demo
uv run credlens model report --experiment-id EXP_demo --model-id MODEL_demo
```

## Reproducibility

Given the same seed, dataset, and configuration, `create-split`/`train`
produce byte-identical split hashes and numerically identical test
metrics (proven directly: two independent runs of the same experiment_id
and seed produced the same combined split hash and the same test
ROC-AUC/PR-AUC/KS to 6 decimal places). `write_reports`'s
`content_fingerprint` excludes the generation timestamp so it is stable
across re-runs of the same experiment, the same distinction Phase 7 gate
E already established for `reports/portfolio_analysis/`.

## Scope boundaries (see the Phase 8 final report for the full list)

- Never trained on the synthetic CredLens portfolio, and never merged
  with `south-german-credit` or any BCB SGS series.
- No origination/credit-granting score, no regulatory PD/LGD/EAD, no
  profit/cutoff optimization, no causal claim, no automated decision.
- Sensitive attributes (SEX/EDUCATION/MARRIAGE/AGE) are audit-only
  (`credlens.modeling.subgroup_audit`) - structurally excluded from
  training by the feature registry, never a model input.
