# Portfolio Analysis Output (Phase 6-7)

Generated by `credlens analysis run` - never hand-edited. Everything here
describes a fully synthetic data-generation process (DGP), not a real
financial institution.

## Contents

- `executive_summary.md` / `executive_summary.pt-BR.md` - short, decision-card-based summary (EN/PT-BR).
- `technical_report.md` / `technical_report.pt-BR.md` - full analytical architecture, SQL provenance, validations, limitations (EN/PT-BR).
- `tables/*.csv` - every query result the analysis run produced, one file per named query in `src/credlens/analysis/metrics.py`/`scenarios.py`.
- `figures/*.png` - every chart `src/credlens/analysis/charts.py` generated from the tables above.
- `insights.yml` - the generated, versioned insights registry (Phase 7 gate D, `credlens.analysis.insights`) - written only when `--insights` is passed to `analysis run`.
- `manifest.json` - provenance: build id, warehouse fingerprint, source hashes, versions, query/table/figure/**report** hashes (`reports_written`, Phase 7 gate E), parameters, warnings, final status.

## Regenerating this directory

```bash
uv sync --extra warehouse --extra analysis
uv run credlens warehouse build --suite-id SUITE_sample_2026
uv run credlens analysis run --build-id <build_id> --force --insights
```

Add `--multiseed` to also run a real multi-seed robustness sweep for one
scenario embedded in this report (see the technical report's "Multi-seed
robustness" section) - this performs real data generation and is not run
by default or in CI. For the completed four-scenario, ten-seed sweep, see
`reports/synthetic_validation/multiseed_robustness.json`
(`credlens.analysis.robustness.full_robustness_sweep`, Phase 7 gate A).

## Reproducibility

`credlens analysis reproduce --output-dir reports/portfolio_analysis` re-runs
the same build_id (with the same recorded parameters, including
`--insights`/`--multiseed` if used) into a separate directory and verifies
every table/figure/**report** content hash matches exactly - the proof
that this output is deterministic, not a one-off. The insights registry's
hash (`content_fingerprint`) deliberately excludes the per-run
`analysis_id`, which is execution metadata, not reproducible content.
