# Independent Model Validation Output (Phase 9)

Generated by `credlens model {validate-independent,audit-collinearity,audit-negative-controls,
compare-candidates,register-challenger}` - never hand-edited. This is a SEPARATE audit layer
(`credlens.model_validation`) over the Phase 8 behavioral early-warning model
(`reports/modeling/`) - every metric here is recomputed with an independent implementation from
FROZEN evidence, never copied from `reports/modeling/technical_report.md`.

## Contents

- `decision.json` - the 14 validation gates and the final decision (`validation_passed` /
  `validation_passed_with_limitations` / `validation_failed`) - a single shared file, always
  reflecting the MOST RECENTLY validated model (see the CI workflow's restorative step for how
  this stays correct for the official model after a CI-scoped smoke run).
- `validation_report.md` / `validation_report.pt-BR.md` - full methodology and gate table (EN/PT-BR).
- `evidence/<experiment_id>.json` - **git-ignored**: the frozen evidence manifest (hashes, IDs,
  original metrics, a `frozen_at_utc` timestamp) - regenerable via `credlens model
  validate-independent`, not needed for review (its content is already duplicated, in stable
  form, in `decision.json` and the tables below).
- `lifecycle/<model_id>.json` - append-only lifecycle transition history
  (`experiment -> candidate/challenger -> validation_passed/validation_passed_with_limitations/
  validation_failed`) - never `production`/`deployed`/`automatically_promoted`.
- `tables/<experiment_id>__*.csv` - **git-ignored** (regenerable): recomputed discrimination/
  calibration/operating-point comparisons, the permutation-test distribution (`.json`), the VIF
  table, high-correlation pairs, coefficient classification, corrected subgroup validation/gaps,
  the robustness spot-check, ECE bin-sensitivity, and the candidate/challenger Pareto comparison.
- `figures/<experiment_id>__*.png` - VIF bar chart, permutation-null histogram, corrected
  subgroup-gap chart, candidate/challenger Pareto scatter.

## Regenerating this directory

```bash
uv run credlens model validate-independent --model-id MODEL_behavioral_default_v1
uv run credlens model audit-collinearity --model-id MODEL_behavioral_default_v1
uv run credlens model audit-negative-controls --experiment-id EXP_behavioral_default_v1
uv run credlens model register-challenger --experiment-id EXP_behavioral_default_v1
uv run credlens model compare-candidates --experiment-id EXP_behavioral_default_v1
```

## Key corrections this phase made (see the Phase 9 final report for full detail)

- Replaced the Phase 8 fixed-band shuffled-target check (`|AUC-0.5|<=0.12`, a single shuffle)
  with a 100-permutation empirical test (`credlens.model_validation.negative_controls`).
- Audited multicollinearity: `months_delinquent_count`/`consecutive_months_delinquent` (VIF ~57/53)
  and `total_bill_amount`/`avg_bill_amount`, `total_payment_amount`/`avg_payment_amount`
  (perfectly collinear, infinite VIF) are classified `redundant` - their reason-code language no
  longer implies a "protective effect".
- Corrected the Phase 8 "max TPR gap = 0.3323" finding: that number was `university`'s OWN true
  positive rate, picked as the gap's maximum only because the minimum came from a `limited`-
  sample group (`undocumented_code`, n=56). The corrected, adequate-groups-only gap is 0.0657
  (`graduate_school` vs. `university`).
- Formalized HistGradientBoosting as a registered `challenger` (never `candidate`/`production`)
  and built a real candidate/challenger Pareto comparison.

## Scope boundaries

- Never a fairness certification, never a legal/compliance assessment.
- No automated promotion to `production`/`deployed` exists anywhere in this codebase's
  vocabulary (`credlens.model_validation.lifecycle`).
- No commit/push, no API, no deploy, no automated retraining.
